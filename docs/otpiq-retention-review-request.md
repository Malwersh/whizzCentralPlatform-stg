# أسئلة سياسة الاحتفاظ لدى OTPIQ

مسودة للمراجعة — 2026-10-14. لم تُرسل إلى المزود. لا تتضمن أرقام عملاء أو OTP أو مفاتيح API.

نستخدم خدمة OTP عبر WhatsApp/SMS ونحتاج توثيق دورة حذف بيانات المستلمين. يرجى توضيح:

1. ما البيانات المخزنة لكل رسالة: رقم المستلم، نص الرمز، حالة التسليم، التوقيت، ومعرف الرسالة؟ وما مدة كل فئة، بما فيها النسخ الاحتياطية؟
2. هل يمكن حذف سجلات مستلم/رسالة تخص حسابنا فقط؟ ما API الرسمي أو مسار طلب الدعم ووقت التنفيذ وإثبات الاكتمال؟ لا نطلب حذف هوية المستلم لدى حسابات عملاء آخرين.
3. ما الاستثناءات المالية/الأمنية/القانونية، وما البيانات المحتفظ بها عند الاستثناء ومدتها؟ هل يزال نص OTP سريعًا؟
4. من المعالجون الفرعيون لقنوات WhatsApp وSMS، وكيف تصلهم طلبات الحذف، وأين تُعالج البيانات؟
5. هل تتوفر اتفاقية معالجة بيانات وسياسة احتفاظ مكتوبة يمكن اعتمادها وإظهارها في سياسة الخصوصية؟

مرجع المراجعة: https://otpiq.com/privacy-policy وhttps://docs.otpiq.com/ . تظهر السياسة حق طلب الحذف دون جدول احتفاظ تفصيلي. راجعنا فهرس https://docs.otpiq.com/llms.txt؛ يعرض إرسال/تتبع الرسائل وتقارير التسليم، وحذف حملة مسودة/مجدولة، ولا يعرض مسار إزالة سجل OTP لمستلم. حذف الحملة ليس إثبات حذف الرسائل الفردية. لا نخمن API للإزالة ولا نعد بنجاح إزالة خارج أنظمتنا دون رد موثق.

بعد الرد: اعتماد السياسة، تعيين مسؤول متابعة، حفظ معرّفات الرسائل الضرورية فقط وفق مدة موثقة إن تطلب API ذلك، ربط الطلبات وتسجيل نتيجة المزود دون رموز تحقق، واختبار حذف رسالة اختبار منفصلة. لا تُرسل هذه المسودة دون تكليف صريح.
