بعد الموافقة والدمج، مع نسخة عمل نظيفة:

git checkout staging-main
git pull --ff-only origin staging-main

بند المنتجات والقوائم والاستيراد CSV/Excel وكل متعلقاته ما زال مفوضًا للزميل، كما في وثيقة التسليم الأصلية. لا تستبدل فرع عمله أو تغيّر ملكية هذا البند عند حل تعارضات لاحقة.

قيود التحقق المعروفة:
