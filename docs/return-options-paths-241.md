# مسارات استلام المرتجع — الجزء ٢٤١

قاعدة الإكمال: لا يكفي وجود خيار في الواجهة. يجب تسجيل شروطه، انتقاله التشغيلي، المسؤول عن متابعته، أثره المالي، نهاية مساره، واختباره. ما لم يكتمل يُسجل كجزء متبقٍ صريح؛ لا يوصف بأنه مطبق بالكامل.

## تحرير الضمان في ٢٤١

متاح للموظف ذي finance.approve وحد اعتماد يغطي مبلغ الضمان. يتطلب اكتمال مهمة الإرجاع بإثبات الاستلام الكامل وقرار مسؤولية ساري مسجل بأدلته، ولا يسمح به إذا كان القرار يحمل السائق مسؤولية مثبتة. يمكن تحريره مع بقاء المسؤولية غير محددة إذا قرر المخول ذلك صراحة بسبب موثق؛ ليس حكمًا بتبرئة طرف أو اعتماد تعويض. مبلغ التحرير من الحجز الأصلي المثبت، لا من حقل مبلغ في المتصفح. لا يُنشئ دينًا، ولا يدفع أجرة أو تعويضًا، ولا يغلق القضية المالية. التكرار بنفس المرجع آمن، وتغيّر القرار أو الصلاحية أو النقد أو الحجز يمنع التنفيذ.

## استكمال الحالات السابقة

إعادة مطابقة من الخادم بإقرار المالك المخزن: كامل + حالة غير MISSING + هوية المالك/الفرع/السائق/العرض/الحجز والمهمة مطابقة، دون تحصيل نقد أو نتيجة مالية سابقة. يسجل التنفيذ باسم SYSTEM ولا ينشئ إقرار مالك أو قرار موظف. يغلق المهمة فقط ويحفظ التلف والإقرار والضمان والقيود المالية. طلب داخلي AWS IAM محصور الحقول، وغير متاح عبر وكلاء HTTP للزبون والسائق والمطعم.

## الأجزاء المالية والجزئية التالية — عمل متبقٍ صريح

- ٢٤٢: اعتماد أجرة الرحلة الأصلية FULL/ZERO/REVIEW وفق إثبات المحاولة والمسؤولية؛ لا إكرامية غير محصلة، وأجرة العودة الإضافية صفر. اعتماد تعويض المطعم وفق الاتفاقية والأدلة والممول، وربطه بالتسويات الجدولية، وتنفيذ الصرف بمرجع مستقل ومنع التكرار. الموجود الآن يسجل المراجعة وقرار المسؤولية فقط؛ لا يعد صرفًا مكتملًا.
- ٢٤٣: توثيق متوقع/مستلم/ناقص/تالف لكل صنف، وحسم العهدة الجزئية مع الإثباتات والتصاريح، وتحديد الجزء المبرر من الضمان وموعد مراجعته وتحرير الباقي؛ معالجة مسؤولية السائق المثبتة والاعتراض دون غرامة تلقائية.
- ٢٤٤: مراجعة تغطية بقية خيارات الإلغاء والاستثناء والنقد والشكاوى على التطبيقات والمنصة. يُصنف كل خيار مرتبطًا بمسار منشور أو بعمل متبقٍ محدد، مع منع وصف المواصفة الكاملة بأنها منتهية.

## خيارات تعذر التسليم والتسليم للفرع

CUSTOMER_UNREACHABLE مرتبط بإثبات الوصول والانتظار ١٠ دقائق وثلاث محاولات تواصل وفق الإعدادات. CUSTOMER_REFUSED لا يفرض هذه المهلة تلقائيًا. DELIVERY_BLOCKED وOTHER يحالان للمراجعة. التصريح التلقائي يستلزم موافقة مالك الفرع وساعات العمل وحالة الفتح ووقت الطريق وهامش ١٥ دقيقة؛ الحالات غير المؤكدة يراجعها المخول.

BRANCH_CLOSED وAUTHORIZED_PERSON_ABSENT وRECEIPT_REFUSED وRECEIVED_WITHOUT_CONFIRMATION وOTHER في بلاغ الفرع تسجل إفادة السائق والموقع والوصف وتبدأ متابعة وتصعيدًا بعد ٥ دقائق. إفادة السائق وحدها لا تثبت خطأ المطعم ولا استلامه. تعليمات الدعم موثقة؛ مرور المؤقت لا ينهي العهدة. التصرف البديل أو الجزئي يخضع للجزء ٢٤٣ ولا يعد منفذًا بمجرد وجود بلاغ.
