# Staging session and loading repair

The reported driver/customer/order failures had multiple confirmed causes: auth guards trusted stored flags without checking expiry; the legacy auth service removed refresh tokens on expiry; AWS clients reused the old identity token; the admin data role omitted WizzOrders read access; dashboard/data-service referenced Dev tables and converted read failures to zero/demo values.

Auth now validates issuer, browser client, token_use and expiry, refreshes with the configured Cognito browser client (ALLOW_REFRESH_TOKEN_AUTH confirmed on the deployed client), coalesces concurrent refresh requests, retains sessions on network failures, clears revoked sessions, and prevents an in-flight refresh from undoing logout. AWS initialization also coalesces requests and replaces clients when the ID token changes. These frontend checks support routing; Cognito and IAM remain the authorization boundary.

Read-only WizzOrders access was added to the existing admins-only role through CloudFormation; no new general write permissions were granted. Orders and shared scans follow pagination, and order history selects only ORDER#/META records. Dashboard customer/driver data use Staging tables. Failed/unconfigured values display a dash rather than zero; demo businesses are removed. Revenue and support metrics remain unavailable until their actual data sources/definitions are implemented. Shared scripts have versioned URLs across platform pages. Finance uses the same session renewal path.

Verification: 15 Node tests passed, including expired/foreign tokens, refresh concurrency, temporary network failures, revoked refresh, logout races, renewed AWS clients, paginated orders and dashboard failed-metric handling. CloudFormation change set modified the existing role and its role attachment without replacement. IAM simulation verifies allowed Scan on WizzOrders, WhizzDrivers_staging and WizzUser_users_staging, with Dev drivers denied. Browser session acceptance remains to be tested by the signed-in administrator; no authenticated browser session was available to the agent.
