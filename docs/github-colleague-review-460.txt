٥. إعدادات الإصدار: تغيير توقيع Android وSDK والأسماء والسياسات الثابتة يمكن أن يعيد مشاكل الخرائط/اسم التطبيق/المظهر. لا تُستورد مع المحادثات ولا تستبدل إصلاحاتنا الأخيرة.
٦. المنصة: مخطط هوية اتصال الدعم الجديد authVersion=2 والجداول الجديدة للمرفقات والإيصالات يحتاج مراجعة ربط النشر والتوافق مع الاتصالات الحالية؛ لا نستبدل معالج WebSocket المشترك دفعة واحدة.
